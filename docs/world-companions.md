# Max and Abi

Personal companions for Amaro and Javiera's world (`7b8edae0-65da-44b7-a9b9-8073ecdd607e`). Max belongs to Javiera; Abi belongs to Amaro. The unrelated Test / User 2 world has no personal pets. The companions appear from level 1, follow the couple across known biomes, and are independent of inventory, rewards and XP. No SQL migration is needed.

Photo references: `C:/Users/amaro/Desktop/caps/max1.png`, `max2.png`, `abi1.png`, `abi2.png`. The existing `public/assets/world/fox-v1.png` was used only as a storybook painting style reference. The photos were visually inspected before generation. Max's identity cues are the black head/floppy ears, white facial blaze and muzzle, long white legs, black saddle marking, brown eyes and black collar. Abi's cues are the petite proportions, tousled cream coat, floppy ears, short dark muzzle, round eyes and protruding pink tongue. Generated full-body views interpret details not visible in the reference photographs.

Created with the built-in image generation tool, with transparent backgrounds. Original character masters remain at `public/assets/world/max-v1.png` and `public/assets/world/abi-v1.png`. Animation masters are `public/assets/world/max-animation-sheet-v1.png` and `public/assets/world/abi-animation-sheet-v1.png`. Each has four walk poses, idle, blink, a play bow and a lying rest pose, with original character art as identity references. Source photographs remain unchanged. Mechanical cell extraction/padding creates compact horizontal WebP atlases with `npm run animate:companions`. Each atlas has eight 256px square frames; Max's is 133,120 bytes and Abi's 158,692 bytes. Max displays at 160 world units, Abi at 96, with a small ground shadow and day/night brightness.

The user requested both companions in the lower grass strip between the path and lake, shared play and name-only greetings. `WorldCompanions` coordinates a shared sequence of approach, pause, Max's play invitation, Abi's response, following and wandering. Position targets stay in a diagonal bank region (bottom 17–22%, adjusted horizontal bounds). CSS transitions move between waypoints with slight following delays; frame animations show actual alternating legs and blinking. Sprite updates run in CSS instead of React per frame. At night both use their lying pose with subtle breathing. Hidden tabs, reduced motion and hammer mode pause the shared routine; all timers and listeners are cleaned up. Taps display exactly “Max” or “Abi” and four soft particles, with no XP. Accessible button labels are also name-only.

Verification includes the couple restriction, level-1 appearance, no global level rewards, alpha in optimized artwork, bounded shared routes and complete walking durations, real sprite frame changes, lower-bank mobile placement, Max's play invitation followed by Abi's response, name-only greetings without XP, lying night poses, reduced motion and hammer interaction blocking, plus the editor tests and production build. Browser scenes use isolated test props, not the user's authenticated database.
